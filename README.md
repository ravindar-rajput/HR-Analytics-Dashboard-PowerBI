# HR Analytics Dashboard | Power BI 📊

## 📌 Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Power BI to transform employee data into meaningful insights and support data-driven decision-making.

## 🎯 Project Objectives
- Analyze employee distribution across departments.
- Explore job title distribution.
- Monitor employee hiring trends.
- Analyze salary distribution by department.
- Explore employee distribution by country.
- Build interactive reports using slicers and filters.

## ✨ Dashboard Features
- Total Employees
- Average Salary
- Department Count
- Job Count
- Employees by Department
- Employees by Job Title
- Hires by Month
- Salary by Department
- Employee Distribution by Country
- Employee Details Table

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📂 Dataset
The project uses seven CSV files:
EMPLOYEES, DEPARTMENTS, JOBS, JOB_HISTORY, LOCATIONS, COUNTRIES, and REGIONS.

**Note:** The dataset consists of representative teaching data and is not a complete official Oracle HR database.
